Ephemeris

Small animated orbs of things in the sky, drawn as dots on one canvas. No dependencies, one script, the same draw contract as thinking-orbs. Four bodies so far: a black hole, a pulsar, a galaxy, a nebula. Colour them with six CSS variables, or run them monochrome.

Theme it

6 css variables

Set any --orb-* custom property on the canvas or an ancestor. Read every frame, so a theme switch or a hover rule applies live. Each mode has its own defaults; set one variable and the rest keep the mode's default. Ink ignores them.

pulsar · ember
the black hole's colours
galaxy · jade
cold #0A7A5A · glow #20B48A
blackhole · orchid
cold #B0186E · glow #E040A0
pulsar · silver
cold #6A6A6A · glow #9A9A9A
canvas.orb {
  --orb-cold:   #1E56D8;   /* far / receding / outer   */
  --orb-mid:    #7FB0FF;   /* mid                      */
  --orb-hot:    #EAF3FF;   /* near / approaching / core */
  --orb-glow:   #3D7BFF;   /* halo + haze              */
  --orb-ring:   #F2F8FF;   /* photon ring (blackhole)  */
  --orb-shadow: #000000;   /* the hole (blackhole)     */
}

Use it. One script, then any canvas with class orb. Height is the preset, width lets a mode stretch. Everything else is a data attribute.

<script src="src/ephemeris.js"></script>

<canvas class=orb width=64 height=64 data-orb-mode=pulsar></canvas>
<canvas class=orb width=64 height=64 data-orb-state=swirling></canvas>
<canvas class=orb width=128 height=64 data-orb-mode=blackhole
        data-orb-lite=1 data-orb-space=1></canvas>

// added later? wire them up
Ephemeris.register(someRoot);
  • data-orb-mode blackhole · pulsar · galaxy, or data-orb-state pondering · pinging · swirling
  • data-orb-ink=1 monochrome, follows the page theme like thinking-orbs
  • data-orb-lite=1 half the particles · data-orb-space=1 dark ground with stars
  • data-orb-arms (galaxy) · data-orb-spin, data-orb-tilt (pulsar)

Or drive it yourself. Every mode is a plain function with the thinking-orbs signature, so it drops into an existing engine too.

Ephemeris.draw('galaxy', ctx, 64, t, dark, {
  arms: 2, lite: true,
  palette: { cold:[10,122,90], mid:[95,216,176], hot:[232,255,246],
             glow:[32,180,138], ring:[255,255,255], shadow:[0,0,0] }
});

// into thinking-orbs
Orbs.MODE_DRAWS.pulsar = Ephemeris.MODES.pulsar.draw;
Orbs.STATE_TO_MODE.pinging = 'pulsar';
  • Paused off-screen and on hidden tabs; DPR capped at 2
  • Reduced motion draws one still frame, repainted on theme change
  • Dot size follows the engine's (size/300)^0.6; counts follow size
